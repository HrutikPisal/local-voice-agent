# `voice` package

Full documentation: **[../README.md](../README.md)** (install, commands, LiveKit, tuning).

Quick start from repo root:

```bash
pip install -r voice/requirements-stt.txt
python -m voice
```

- STT tuning: [../docs/STT_TUNING.md](../docs/STT_TUNING.md)
- LiveKit: [livekit/README.md](livekit/README.md)
- Tests: `python -m unittest discover -s voice/tests -p "test_*.py"`

Also developed inside [LocalCLIagent](https://github.com/HrutikPisal/LocalCLIagent); this repo is the public home for the voice stack.
